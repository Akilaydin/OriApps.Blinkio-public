# Blinkio

Blinkio — Telegram-бот для быстрых личных напоминаний и простого планирования.

Открыть бота: [@Blinkio_Bot](https://t.me/Blinkio_Bot).

Основные возможности:
- одноразовые и повторяющиеся напоминания;
- быстрый ввод, шорткаты и настраиваемые кнопки;
- список напоминаний, календарное расписание и ежедневный план;
- snooze, редактирование, вложения и Google Calendar.

Подробное описание всех функций: [MANUAL.md](MANUAL.md).

Если нашли баг или хотите предложить новую функцию, создайте [Issue](https://github.com/Akilaydin/OriApps.Blinkio-public/issues).

Этот репозиторий содержит только публичную пользовательскую документацию Blinkio. Исходный код приложения здесь не публикуется.
