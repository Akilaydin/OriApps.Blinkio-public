# Blinkio — руководство пользователя

Blinkio — Telegram-бот для быстрых личных напоминаний. Напоминание обычно создаётся одним сообщением, а основные действия выполняются кнопками прямо в чате.

## Быстрый старт

Самые частые варианты:

```text
+30m Купить хлеб
@18:00 Позвонить Диме
@23.11 09:00 Врач
r135 10:00 Стендап
```

Если отправить просто текст без времени, Blinkio создаст одноразовое напоминание через интервал по умолчанию. Изначально это 30 минут.

Команда `/start` регистрирует пользователя, показывает краткую справку и нижнюю клавиатуру быстрых действий. `/help` показывает короткую шпаргалку и ссылку на эту инструкцию.

## Создание одноразовых напоминаний

### Через интервал

Формат:

```text
+<интервал> <текст>
```

Примеры:

```text
+30m Купить хлеб
+2h Позвонить Диме
+1h30m Проверить загрузку
+1h30 Проверить загрузку
+1d Оплатить счёт
```

Единицы: `d` — дни, `h` — часы, `m` — минуты. Поддерживаются и русские варианты `д`, `ч`, `м`. Регистр не важен. Большие значения автоматически нормализуются: например, `+90m` превращается в 1 час 30 минут.

Если отправить только время без текста, например `+30m`, бот попросит ответом написать текст напоминания.

### В конкретное время

Формат для ближайшего указанного времени:

```text
@18:00 Позвонить
```

Поддерживаются варианты `@18:00`, `@1800` и `@18 00`. Минуты обязательны: запись вроде `@18` не поддерживается. Если время сегодня ещё не наступило, напоминание будет сегодня; если уже прошло — завтра.

### В конкретную дату

Полная дата:

```text
@2026-11-23 09:00 Врач
```

День и месяц текущего года:

```text
@23.11 09:00 Врач
```

Также поддерживается компактная запись без точки, например `@2311 0900`. Если такая дата уже прошла в текущем году, нужно явно указать год.

Только день месяца:

```text
@10 09:00 Оплатить интернет
```

Если указанное число уже прошло в текущем месяце, Blinkio использует следующий месяц. Если в следующем месяце такого числа нет, бот вернёт ошибку.

### По дню недели

Можно указать ближайший день недели:

```text
@пн 18:00 Зал
@mon 18:00 Зал
```

Поддерживаются русские и английские сокращения и полные названия дней недели. Если выбран сегодняшний день, но время уже прошло, будет использована следующая неделя.

## Повторяющиеся напоминания

Формат:

```text
r<дни> <время> <текст>
r/Nd <время> <текст>
```

В первом формате дни недели кодируются цифрами: `1` — понедельник, ..., `7` — воскресенье. Во втором `N` — количество календарных дней между срабатываниями.

Примеры:

```text
r135 10:00 Стендап
r12345 09:00 Работа
r1234567 08:30 Зарядка
r/21d 10:30 Врач
r/3d 18:45 Тренировка
```

Порядок обязателен: сначала `r<дни>` или `r/Nd`, затем время, затем текст. Время должно включать минуты, например `10:00`, `1000` или `10 00`. Повторяющееся напоминание без текста не создаётся.

Для `r/Nd` первое срабатывание будет в ближайшее указанное время сегодня или завтра. Дальше напоминание повторяется через N календарных дней в то же местное время. Пропуск, изменение времени, смена часового пояса и перерыв в работе бота не начинают новый цикл.

Snooze повторяющегося напоминания не сдвигает его постоянное расписание: Blinkio создаёт отдельное временное одноразовое срабатывание, а основной повтор продолжает идти по своему шаблону.

## Обычный текст и интервал по умолчанию

Если сообщение не является командой, шорткатом или выражением времени, оно воспринимается как текст быстрого напоминания:

```text
Купить хлеб
```

По умолчанию оно сработает через 30 минут. Интервал меняется командой:

```text
/default_delay 1h
```

Сброс:

```text
/default_delay reset
```

## Быстрые кнопки

После `/start` или `/help` доступна нижняя клавиатура Telegram. По умолчанию на ней есть интервалы `+15m`, `+30m`, `+1h`, `+2h`, `+1d` и кнопка `📅 Сегодня`. Бот повторно показывает клавиатуру в обычных ответах, когда сообщение не использует другие кнопки или режим ответа.

Если клавиатура скрылась или пропала, отправьте `/keyboard` — бот покажет её снова.

При нажатии кнопки времени, например `⏱ +30m`, бот попросит ответом ввести текст напоминания.

Набор интервалов можно изменить:

```text
/quick 10m 30m 1h 3h
```

Сброс к стандартному набору:

```text
/quick reset
```

Кнопка `📅 Сегодня` не входит в пользовательские пресеты и остаётся доступной независимо от `/quick`. Она эквивалентна `/calendar 1`.

## Просмотр напоминаний

### `/list`

Показывает активные одноразовые и повторяющиеся напоминания, ближайшие сверху. Они группируются по датам.

Под списком находятся нумерованные кнопки. Нажмите номер напоминания, чтобы открыть действия с ним.

Для одноразового напоминания доступны:
- изменение текста;
- изменение времени;
- удаление.

Для повторяющегося:
- изменение текста;
- изменение постоянного времени;
- пропуск следующего срабатывания;
- удаление.

Успешные действия в `/list` не засоряют чат: список обновляется в том же сообщении, а удаление и пропуск дополнительно подтверждаются коротким уведомлением. После выбора `Текст` или `Время` список сразу возвращается в общий вид; временные сообщения редактирования после успешного ввода удаляются. Ошибки остаются отдельными сообщениями, чтобы их можно было скопировать.

### `/calendar [дней]`

Показывает расписание с учётом всех срабатываний повторяющихся напоминаний.

```text
/calendar
/calendar 1
/calendar 5
```

Без аргумента показывается период до конца текущей недели. Можно запросить от 1 до 7 дней. `/calendar 1` показывает только сегодня.

## Ежедневный план

Blinkio может автоматически присылать оставшееся расписание на текущий день в заданное время.

Включить:

```text
/daily_plan 09:00
```

Также принимается компактный формат:

```text
/daily_plan 0900
```

Посмотреть текущую настройку:

```text
/daily_plan
```

Выключить:

```text
/daily_plan off
```

В сводку попадают оставшиеся на момент отправки одноразовые и повторяющиеся напоминания за сегодня. Если оставшихся напоминаний нет, сводка не отправляется.

## Редактирование и удаление

### Изменить текст

Кнопка `Текст` доступна после создания одноразового напоминания и в управлении через `/list`.

Бот показывает текущий текст. Если он достаточно короткий для Telegram, появляется кнопка `Скопировать текст`; затем бот просит ответом прислать отредактированный вариант. Меняется только текст напоминания.

### Изменить время одноразового напоминания

В `/list` выберите напоминание и нажмите `Время`.

Поддерживаются, например:

```text
+30m
18:00
@18:00
2026-11-23 09:00
@23.11 09:00
```

В этом сценарии для абсолютного времени `@` можно опустить.

### Изменить время повторяющегося напоминания

Для повторяющегося напоминания в `/list` используется кнопка `Время`.

Примеры:

```text
18:00
1800
@18:00
```

Меняется постоянное локальное время повторяющегося шаблона. Дни недели или интервал `r/Nd` остаются прежними, а ближайшее срабатывание сразу пересчитывается в часовом поясе пользователя. Для `r/Nd` последовательность дат не меняется. Даты, дни недели и относительные интервалы вроде `+1h` здесь не принимаются.

### Пропустить

Кнопка `Пропустить` у повторяющегося напоминания переносит его на следующее срабатывание по обычному расписанию, не удаляя сам повтор.

### Удалить

Удаление доступно из управления `/list`, а у повторяющегося напоминания — также из уведомления о срабатывании.

## Когда напоминание сработало

Под уведомлением находятся кнопки snooze, `Custom` и `✅ Готово`. Для повторяющихся напоминаний также доступны действия изменения текста и удаления.

### Snooze

Стандартные интервалы: `+15m`, `+30m`, `+1h`. Нажатие переносит напоминание на выбранный интервал от текущего момента.

Набор кнопок можно настроить:

```text
/snooze 10m 30m 1h 2h
```

Сброс:

```text
/snooze reset
```

### Custom

`Custom` позволяет указать своё время. Ответьте на запрос бота, например:

```text
+2h
@18:00
@2026-11-23 09:00
@23.11 09:00
```

Можно также ответить непосредственно на само уведомление — в том числе через быстрый ответ из шторки Telegram — выражением времени (`+30m`, `+1h`, `@18:00` и т. п.). Это работает как пользовательский snooze.

### `✅ Готово`

Помечает показанное уведомление как выполненное и убирает его кнопки. Для повторяющегося напоминания это не отключает будущие повторы.

## Шорткаты

Шорткат сохраняет готовый шаблон напоминания и запускается одной короткой командой.

Создать:

```text
/shortcuts add gym +30m Сходить в зал
/shortcuts add reports r135 12:00 Проверить отчёты
```

Использовать:

```text
!gym
```

Показать список:

```text
/shortcuts list
```

Удалить:

```text
/shortcuts remove gym
```

Имена регистронезависимы. Повторное `add` с тем же именем обновляет существующий шорткат. Шаблоном может быть одноразовое относительное, абсолютное или повторяющееся напоминание.

## Часовой пояс

Все даты и время рассчитываются в часовом поясе пользователя. По умолчанию используется `Europe/Moscow`.

Изменить:

```text
/timezone Europe/Moscow
/timezone Europe/Berlin
/timezone Asia/Tbilisi
```

Поддерживаются идентификаторы часовых поясов, которые распознаёт сервер. Также можно использовать `Etc/GMT`, например `Etc/GMT-3` для UTC+03:00; у `Etc/GMT` знак обратный.

При смене часового пояса Blinkio пересчитывает активные напоминания так, чтобы их локальное расписание соответствовало новому часовому поясу.

## Google Calendar

Подключение запускается командой:

```text
/google_connect
```

Бот пришлёт ссылку для авторизации Google. Если интеграция на сервере отключена, будет показано сообщение о недоступности.

После подключения Google Calendar под создаваемыми одноразовыми напоминаниями появляется кнопка `📅 Добавить в календарь`. Она создаёт событие в Google Calendar. Без подключения кнопка не показывается. Повторное нажатие для того же напоминания не создаёт дубликат.

Ограничения:
- добавление в календарь доступно только для одноразовых напоминаний;
- изменение или удаление напоминания в Blinkio не изменяет уже созданное событие Google Calendar;
- автоматической двусторонней синхронизации нет.

## Вложения

К напоминанию можно прикрепить одно:
- фото;
- видео;
- GIF-анимацию;
- документ.

Время и текст можно указать в подписи:

```text
+30m Посмотреть документ
@18:00 Отправить фото
```

Если в подписи указать только обычный текст, будет использован интервал по умолчанию, как и для обычного текстового сообщения.

Вложение сохраняется с напоминанием и показывается при срабатывании. Оно также сохраняется при snooze и отметке `Готово`.

Не поддерживаются:
- альбомы из нескольких медиафайлов;
- голосовые сообщения;
- видеокружочки;
- стикеры.

Для медиа без подписи бот попросит добавить текст/время.
